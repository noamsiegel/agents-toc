# AGENTS.md

This file orients agents working on **agents-toc** itself. Read `CONTEXT.md`
for the load-bearing invariants (marker ownership, idempotency, module map).
See `README.md` for the user-facing surface.

## How to work here

- Code edits go in `cmd/` (thin shells) or `internal/<package>/` (real logic).
- Add tests next to the code: `*_test.go` in the same package.
- Run `go test -race ./...` before yielding.
- Never write outside the markers in any project's `AGENTS.md` — that's the
  single invariant this tool exists to protect.
